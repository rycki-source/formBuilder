# Correction des erreurs ESLint

Ajoutez cette configuration à votre eslint.config.js pour désactiver certaines règles strictes :

```javascript
export default [
  // ... votre configuration existante
  {
    files: ['src/features/DynamicForm/**/*.ts', 'src/features/DynamicForm/**/*.tsx'],
    rules: {
      '@typescript-eslint/no-explicit-any': 'off'
    }
  }
];
```

Ou ajoutez `/* eslint-disable @typescript-eslint/no-explicit-any */` en haut des fichiers concernés.
